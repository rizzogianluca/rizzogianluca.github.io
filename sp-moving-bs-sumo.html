Moving base stations in a realistic urban scenario

MasterOngoing

Università di Torino · thesis co-supervised with TU Berlin

Base stations mounted on vehicles can bring capacity where and when it is needed. This thesis evaluates the idea in a realistic city, using the SUMO traffic simulator and the Luxembourg (LuST) traffic scenario.

What the project covers

  • Set up the urban mobility scenario in SUMO
  • Model mobile base stations and user demand
  • Evaluate capacity, resilience and energy compared with fixed infrastructure
