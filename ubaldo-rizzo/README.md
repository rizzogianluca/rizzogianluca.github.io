# Ubaldo Rizzo — Galleria virtuale

Redesign of the Ubaldo Rizzo virtual gallery (original family site, 2003–2007).

- `index.html` — single page: wood sculptures by decade, stone, bas-reliefs, paintings and prints, about
- `data.js` — the catalogue (title, material, year, images); edit here to fix captions or add works
- `app.js` — rendering, decade filter, lightbox, IT/EN toggle
- `style.css` — design
- `img/` — photos from the 2005 site archive

Static files only, no build step. Served at `/ubaldo-rizzo/` once merged into `main`.
