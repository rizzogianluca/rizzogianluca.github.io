Urban mobile network performance simulator

BachelorOngoing

Università di Torino · Bachelor thesis

The goal is a simulation tool that, given the position of base stations and the distribution of users in a city, estimates the coverage and capacity that a mobile network can offer.

The simulator is meant as a basis for later studies on dynamic networks, such as base stations mounted on vehicles.

What the project covers

  • Model base stations, users and radio propagation in an urban area
  • Implement and validate the simulator
  • Compare network configurations through simulation experiments
