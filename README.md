# rizzogianluca.github.io

Personal academic website of Gianluca Rizzo, published with GitHub Pages at https://rizzogianluca.github.io.

## How it is built

The pages are plain HTML generated by a small Python script, with no dependencies:

```
python3 src/build.py
```

- `src/build.py`: page content (home, research, projects, teaching, people, CV), news items, templates, structured data, sitemap.
- `src/publications.txt`: the publication list, one line per paper (see the header of the file for the format). Mark a paper with `selected` to show it among the selected publications, or with `award:…` to show an award badge.
- `style.css`: all styles.
- `network/`: password-protected page (StatiCrypt), not generated by the script and excluded from search engines.

To update: edit the files in `src/`, run the build, commit and push. GitHub Pages republishes within a minute.
